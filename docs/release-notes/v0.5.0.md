# CC Switch X v0.5.0

本版本在备份面板新增 WebDAV 云备份，把本地快照上传到自托管的 WebDAV 存储并可从云端恢复；同时改用自绘标题栏、支持开机自启，并把备份与 Git 命令改为异步执行。

## WebDAV 云备份

- 备份面板新增「云备份（WebDAV）」区块：配置地址、用户名、密码、远端目录后可测试连接、保存设置、立即上传或从云端恢复；密码只写入本机 `secrets.local.json`，界面留空表示保持不变。
- 远端固定为单槽对象 `<远端目录>/ccswitchx-backup.zip`（目录默认 `ccswitchx`），每次上传覆盖；多机共用同一远端目录时以最后上传为准。备份包为明文 ZIP，请仅配置可信的 WebDAV 服务。
- 打包内容与本地快照一致：`manifest.json`（逐文件 SHA-256）、`assets/`、已知 Agent 的 `agents/*.json` 与 `.gitignore`；不打包 `local/`、`state/`、密钥、索引、日志、历史备份与 `.git/`。上传前逐文件校验，末尾 HEAD 比对大小。
- 上传采用原子替换：先传临时对象再 `MOVE` 覆盖目标，不支持 `MOVE` 的服务回退为直写，且直写成功后才清理临时对象，中途失败不会留下半份备份。
- 从云端恢复需二次确认：先下载并校验 manifest，再复用本地恢复流水线——恢复前自动创建安全快照，白名单覆盖、逐文件校验、失败按安全快照回滚，完成后重建索引。应用不会自动下载或自动恢复。
- 自动快照任务成功创建快照后可按其结果直接上传云端（开启「自动快照后自动上传」时），上传在后台线程执行，失败只记录状态不打扰界面。

## 界面与体验

- 窗口改为无边框自绘标题栏，支持拖动与最小化、最大化、关闭；侧栏按资产、工具、管理分组，常用资产置顶、管理入口固定在底部。
- 设置中新增开机自启：Windows 写注册表 Run 键、macOS 写登录项、Linux 写 XDG autostart，均无需管理员权限；写入后回读确认，界面状态与系统一致。
- 多选筛选下拉重写：点选项不再收起，点击外部或按 Esc 才关闭；移除 MCP 需重启的常驻提示，统一表格与筛选控件的字号和留白。
- 备份快照的列出、重命名、删除、占用统计以及 Git 状态查询与远端设置改为异步执行，不再阻塞界面。
