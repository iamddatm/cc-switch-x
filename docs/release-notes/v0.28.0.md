# CC Switch X v0.28.0

这一版补上 pi 的完整提示词结构，并把提示词编辑与落盘漂移的处置边界理清。

## pi 提示词分成三块

选中 pi 时，提示词页出现「提示库 / 系统提示 / 模板」三个区块：

- **提示库**：仍是 `~/.pi/agent/AGENTS.md` 的整文件接管，和其他 Agent 的提示词用法一致。
- **系统提示**：直接管理 pi 的两个固定文件——`APPEND_SYSTEM.md`（追加在 pi 自带系统提示之后，推荐）与 `SYSTEM.md`（整份替换）。文件存在即生效，没有启用开关。
- **模板**：管理 `~/.pi/agent/prompts/<name>.md`，保存后作为 `/<name>` 斜杠命令使用；支持新建、改名、编辑与删除。

写入口径：

- 每次读取带 revision，保存或删除时文件已被外部改过就拒绝，不用旧视图覆盖。
- 覆盖或删除前把原内容留底到 `backups/pi-prompts/`，保留最近 50 份；写入为原子替换。
- 写命令仍走能力闸与 Agent 检测门禁；模板名只允许字母、数字、点、下划线与连字符，并挡住 Windows 保留名。
- 支持 `baseOverride`，沙箱验证不会碰真实 `~/.pi/agent`。

## 目标文件差异回到漂移横幅

- 编辑提示词的表单里不再内嵌「目标文件与真源不一致」提示和替换按钮。
- 真源与目标文件不一致本身就是落盘漂移，统一在列表上方的漂移横幅里处置：采纳磁盘（改真源）或重刷真源（改磁盘）。
- 横幅文案改得更直白：`有 N 个文件与真源不一致，处理完才能启用或停用。`

## 路径与名称统一

- 声明式路径按平台重新拼接：Windows 上统一为反斜杠，不再出现 `C:\Users\Administrator\.claude/CLAUDE.md` 这种混用分隔符；台账里记录的路径同样整齐。
- pi 的展示名统一为 `pi`（Agent 列表、会话列表与相关提示一致）。
