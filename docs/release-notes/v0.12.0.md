# CC Switch X v0.12.0

这一版把代理从「清空地址才能停用」改成独立开关，并让落盘状态条在一致时彻底消失，手动重扫收进设置。

## 代理支持独立启停

- 设置文件新增 `proxy.enabled`：关闭后**保留代理地址、用户名与密码**，所有出站请求（Skills 下载、skills.sh 搜索、WebDAV、应用更新）直接走网络；重新勾选即可恢复，不用再清空重填。
- 网络面板顶部新增「启用代理」复选框，停用后保存提示「代理已停用，出站请求将直连。」；「清空」按钮仍会连同地址与凭据一起删除。
- 旧设置文件没有该键时按开启处理，现有代理配置不受影响；停用状态仍会校验已保存地址的合法性，避免存下一份无法启用的配置。

## 落盘状态条只在有问题时出现

- 「落盘与真源一致」不再常驻每个页面：读取中与一致时状态条完全隐藏，只有存在漂移或检查失败时才显示。
- 「重扫落盘」与当前状态移到 **Settings → 落盘检查**，检查结果仍通过全局事件同步；有漂移时顶部状态条会自动重新出现。逐条处置仍在各面板顶部的漂移横幅里。
