# CC Switch X v0.24.0

这一版给云备份补上阿里云 OSS 通道，并把远端备份方式从单选按钮改成标签页：Git、WebDAV、阿里云 OSS 各自一块配置，切换标签只换显示，未保存的填写不会丢。

## 阿里云 OSS 云备份

- 新增「阿里云 OSS」通道，走 OSS 的 S3 兼容接口（AWS Signature V4 签名），只依赖对象读写权限。
- 与 WebDAV 共用同一套同步流水线：真源变化后延迟防抖上传、启动与每 15 分钟检查云端、云端有更新时覆盖本机前自动建安全快照、manifest 校验与失败回滚、认证失败自动暂停一小时。
- 连接配置：地域（如 `cn-hangzhou`）、Bucket、对象前缀（相当于 WebDAV 的远端目录）、AccessKey ID 与 Secret；Secret 只存本机 `secrets.local.json`。
- 两个通道的连接配置并存保存，凭据分开存放；同一时刻仍只能启用一种云端备份，切通道会作废旧同步基线。与 Git 备份的互斥关系不变。
- 网络面板的「云端备份走代理」开关对 OSS 同样生效。
- 建议用只授予目标 Bucket 对象读写权限的 RAM 子账号，不必授予整个账号的 OSS 权限。

## 远端备份方式改为标签页

- 顶部改为 **Git 备份 / WebDAV / 阿里云 OSS** 三个标签页，只显示当前标签页的面板，页面不再把三种方式堆在一起。
- 三个面板保持挂载，切换标签页时未保存的表单草稿完整保留，切回来可以继续填写。
- 启用与停用入口移到各自面板内：Git 面板提供「启用 / 停用 Git 备份」，云备份面板提供「启用 WebDAV / 阿里云 OSS 备份」与「停用云端备份」；标签栏下方标明当前启用的通道。
- 手动上传、从云端恢复与远端状态展示跟随当前配置的通道；自动上传 / 自动下载仍需先启用通道。

## 说明

- 升级后旧的 WebDAV 配置原样保留，设置文件缺 `provider` 时按 WebDAV 读取。
- OSS 通道的联网验证需要你自己的 AccessKey；面板里的「测试连接」不会上传任何内容，只探测备份对象是否存在。
