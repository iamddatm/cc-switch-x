# CC Switch X v0.29.0

这一版让 Skills 页回答一个实际问题：哪些 Skill 真的在用。

## 近 30 天调用次数

- 每个 Skill 卡片上显示「近30天 N 次」，数据来自本机会话索引里 `Skill` 工具的调用记录。
- 统计按 Skill 调用名聚合（`{"skill": "名称"}` 的入参），再按名称匹配 `SKILL.md` 里的 name，没有 name 时用目录 id 兜底。
- 最近 30 天更新过的会话里，超过 4 KiB 被索引截断的超长消息也能取到调用名（入参里 `skill` 键排在最前，解析失败时退化为前缀提取）。
- 只读派生索引：不扫描、不复制会话内容进 `assets/`、`local/` 或备份，删掉 `index.db` 也能随时重建。

## 排序与刷新

- 筛选栏新增排序选择：默认排序、调用次数从高到低、调用次数从低到高；次数相同时按名称排。
- 跨天第一次进入 Skills 页会自动增量扫描一次会话再统计；同一天再进入只读索引，不重复扫描。
- 「更多操作」里新增「刷新调用统计」，随时手动重扫并重算；统计进行中会显示加载状态。
- 扫描失败时仍旧显示索引里的旧数据，并提示错误，不会把「今天已刷新」记错。

## 其他

- 修正路径规范化相关测试的断言（v0.28.0 之后的测试修正，不影响用户行为）。

- `cargo test`：单测 690 通过，集成测试 7 通过、2 项真机用例默认忽略；新增 `skill_usage_counts_only_recent_skill_tool_calls` 覆盖时间窗口、截断消息、工具结果与非 Skill 工具入参。
- `pnpm build`（含 `tsc -b`）、`cargo check` 与 `node scripts/check-release-version.mjs` 通过（v0.29.0）。
