# CC Switch X v0.3.0

本版本完善 Skills 发现与更新流程：skills.sh 增加趋势榜，更新检查在切换页面后仍保留，列表筛选可按 Agent 与启用状态组合。

- 发现页切到 skills.sh 时默认展示「Trending (24h)」趋势榜，无需先输入关键词；支持继续加载更多，清空搜索词即可从搜索结果回到趋势榜。
- Skill 更新检查改为跨页面保留：切走再回来仍能看到检查进度与上次结果，不再因为离开面板而丢失。
- 检查到可更新项后自动弹出「全部更新」确认；确认框会列出生效的 Skill 名称与来源仓库，更新或删除后对应条目立即从可更新列表移除。
- Skills 列表的筛选拆分为「Agent」和「启用状态」两个下拉，可组合查看某个 Agent 已启用或未启用的 Skill。
- 趋势榜复用统一的分页合并与已安装索引，减少大列表下的重复扫描。
