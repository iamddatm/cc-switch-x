# CC Switch X v0.7.0

上一版的项目范围只管 Skills；这一版把它扩展到「会话」，并修掉项目路径与侧栏切换的两处别扭。

## 会话按项目自动过滤

- 侧栏选中项目后，「会话」面板只列出项目目录**及其子目录**里产生的会话，搜索命中同样按项目过滤；切回「全局配置」恢复全量，没有额外开关。
- 归属判定先把两边路径归一化再比较：注册表里是 Rust `PathBuf` 的 Windows 写法（`D:\repos\ai\App`），会话的 `cwd` 是各 agent 会话文件里原样取出的字符串，分隔符与盘符大小写都不保证一致。匹配按路径分隔符边界做前缀判断，`App` 不会命中同级的 `Appweb`。
- 没有记录 `cwd` 的会话无法判断归属，项目范围内不显示，并给出被剔除的条数，避免看起来像会话丢了。
- 「按应用」下拉里每一项的计数与总数改为按当前项目的集合统计，否则会出现「Claude (300)」而列表只有几条；项目范围内只剩一个项目，「按项目」分组等于一片空白，因此该范围下隐藏分组切换、直接按时间平铺，行内也不再重复项目名。
- 过滤在前端完成，后端与真源未改动（`index.db` 仍然只是缓存）。代价是它发生在截断之后：本机已索引会话超过 2000 条、或搜索命中超过 500 条时，项目范围内可能看不全更早的记录，面板会说明这个口径。

## 侧栏：选中项目即切到项目范围

- 下拉里去掉「全局配置 / 项目」分段切换：首行是「全局配置」，点项目行同时选中项目并进入项目范围，不再出现全局与项目同时打勾。
- 修掉一个既存缺陷：项目行内 ⋯ 菜单的弹层 portal 到 `body`，而下拉在 `pointerdown` 捕获阶段判定「点到外面」就把自己卸载，菜单项的 `click` 永远收不到，「在文件夹中显示 / 重新定位 / 移除项目」三项全部点不动。按真实事件序列补了回归测试。

## 项目路径恢复可读

- 添加项目时 Windows `canonicalize` 加上的 `\\?\` 逐字前缀一律去掉：注册表、UI 与「在文件夹中显示」拿到的都是 `D:\repos\ai\App` 这样的可读路径；同一项目的逐字与非逐字写法不会再登记成两条。
