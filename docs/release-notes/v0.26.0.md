# CC Switch X v0.26.0

这一版让提示词真正能「集中起来」：把散落在各 Agent 目标文件里的提示词一键收进真源，表单只留名称和说明，ID 自动生成；编辑启用中的提示词时还能直接对照并从目标文件拉回内容。

## 从 Agent 目标文件导入

- 提示词面板的「⋯」菜单新增「从 Agent 目标文件导入」。
- 扫描各已启用 Agent 的目标文件（如 `~/.claude/CLAUDE.md`、Codex 的 `AGENTS.md`），列出非空内容，可勾选多条一次导入。
- 已有对应条目（该 Agent 的启用项或同名提示词）会标记「将更新」：保留原来的名称与说明，只替换正文；没有的按 `{Agent 名称} 提示词` 新建。
- 导入后自动把该 Agent 指向这条提示词；目标文件只读，复制不移动。
- 导入完成逐条报告结果，单条失败不影响其余条目。

## 提示词表单与列表

- 新建提示词不再要求填写 ID：按名称自动生成，中文标题回退为 `prompt`，重名自动加序号。
- 列表行只显示名称和说明，不再显示内部 ID、文件大小和更新时间。
- 编辑当前启用中的提示词时，如果目标文件内容与真源正文不一致，正文上方会出现提示，可一键「替换成目标文件」；替换后仍需保存才写回真源。
