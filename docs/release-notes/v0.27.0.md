# CC Switch X v0.27.0

这一版把提示词页的目标文件变成可操作的入口，并让列表显示可信的「最后更新时间」。

## 目标文件可点击打开

- 提示词页顶部显示的目标文件路径（如 `~/.claude/CLAUDE.md`）现在可以点击，用系统默认程序打开。
- 「从 Agent 目标文件导入」对话框里每个 Agent 的路径同样可以点击打开。
- 打开路径由后端按 Agent 注册表解析，前端不能传任意路径；文件不存在时提示「目标文件还不存在」。
- 新增后端只读命令 `open_prompt_target`，不建目录、不写盘。

## 显示配置的更新时间

- 提示词列表在说明后显示「更新于 X 分钟/小时/天前」。
- 这个时间取自配置的保存记录（应用内保存、导入时写入），不使用真源文件的修改时间（mtime）。
- 修复了启动时全量重建索引会把所有条目的更新时间刷成「现在」的问题：内容没变的条目沿用原时间，内容变化时才更新为这次落盘的时刻。

## 验证

- `pnpm test`：**271 通过**（27 个文件，v0.26.0 是 269），新增覆盖：配置更新时间显示、点击目标文件路径。
- `pnpm build`（含 `tsc -b`）、`cargo check` 与 `node scripts/check-release-version.mjs` 通过（v0.27.0）。
- 索引重建保留时间的改动通过隔离环境中的 `index::` 单测（10 项，含新增用例）。
