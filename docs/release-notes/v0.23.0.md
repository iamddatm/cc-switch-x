# CC Switch X v0.23.0

这一版补上 Skills「未纳管」页缺的最后一块：盘上那些不归我们管的副本，现在可以直接在面板里删掉，不必再去文件管理器里扒目录。

## 未纳管：可删除盘上副本

- 「未纳管」页的「可导入」与「真源里已有同名条目」两个分组，每行都新增「删除」按钮。
- 确认框先列清楚这次会动到哪几处：每一处的落点路径，以及该处是**链接**（只解链）还是**目录**（整份留底后删除）。链接的目标内容一个字节都不动；真实目录先整份备份到 `<storeRoot>/backups/skills/`，留底成功才允许删除，删除失败会报告并保留原目录。
- 删除顺序先解链、后删真身：指向 `.agents/skills` 这类共享真身的链接先断开，再删真身，不留悬空链接。
- 删除前复核归属：指向真源的链接、带 `.ccswitchx` 标记的副本归「已安装」面板管，这里拒绝删除并提示去已安装里停用或卸载。
- 只删盘上副本，不动中央库真源，也不改启用矩阵；删除完成后自动重扫，页签计数与横幅同步更新。
- 目录名仍是唯一入口，实际路径由后端重新扫描定位，前端传来的路径不参与写盘。

- `pnpm test`：**261 通过**（27 个文件，v0.22.0 是 259），新增覆盖：删除确认框逐处说明删除方式、删除后重扫、拒绝删除的原因原样显示。
- `pnpm build`（含 `tsc -b`）与 `node scripts/check-release-version.mjs` 通过（v0.23.0）。

## 说明

- 删除不可撤销，只能从 `backups/skills` 下的留底还原目录副本；链接删除后目标内容仍在原处。
- 一个未纳管条目在多个 agent 落点与共享目录里都有副本时，删除是整条处理，确认框会列出全部位置。
