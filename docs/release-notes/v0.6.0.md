# CC Switch X v0.6.0

本版本新增**项目级 Skills 管理**：可以把 git 管理的项目加进来，查看同一个项目里各 agent 的 skills 目录，并把只写给一个 agent 的 skill 同步到其他 agent。解决的是「我只写了 Claude 的 skill，忘了同步到 Qoder」这类遗漏；项目内容仍由仓库自己的 git 管理，应用不做跨机器同步，也不在项目里放第二份内容。

## 全局 / 项目两个范围

- 侧栏顶部新增一行范围切换：默认「全局配置」，切到「项目」后展示项目列表与「添加项目…」。
- 项目按最近打开排序，行尾菜单提供「在文件夹中显示」「重新定位」「移除项目」；路径失效的项目会标注「路径不存在」并引导重新定位。移除项目只从本机注册表删除，不碰项目文件，也不删项目里的记录文件。
- 添加项目走系统目录选择器。主目录本身、CC Switch X 数据目录内部、以及 `~/.claude`、`~/.qoder` 等用户级 agent 配置目录一律拒绝，避免把用户级配置当项目扫描。
- 项目范围只支持 Skills（当前唯一支持项目级的资产），其余资产入口保留但置灰，悬停说明「仅支持全局配置」；停在 MCP 等面板时切到项目范围会自动跳到 Skills。

## 项目 Skills 矩阵与同步

- 矩阵列出项目里所有 skill（含只有部分 agent 拥有的），每个物理目录一列：`.claude/skills`（Claude Code）、`.qoder/skills`（Qoder / Qoder CN）、`.agents/skills`（Codex / Gemini / Pi），单元格显示有 / 无 / 不同 / 未跟踪 / 不可用。
- 添加项目时立即在项目里写入 `.ccswitchx/skills.json`：只记录每个目录当时的文件清单与树哈希，**不复制、不删除任何内容**，所以首次进入项目看到的是「未跟踪」而不是被强行补齐。这个文件跟随仓库提交，不含绝对路径。
- 单元格即「同步到该目录」的勾选。勾选只写记录，落盘由同步完成：新勾选且缺失的目录会复制过去，新勾选但内容不一致的目录会报冲突而不是被覆盖；取消勾选只保留文件与记录。
- 同步以「最后一次操作」为准：恰好一个目录发生变化（新增、修改、删除任一）时，把该状态传播到其他已勾选目录——删除同样传播。比较的是整个 skill 目录（逐个文件的 SHA-256 汇总），不只是 `SKILL.md`。
- 两个以上目录同时变化、或删除与其他改动并存时一律视为冲突，不自动写盘；弹框逐条人工裁决「保留某一边」或「两边都保留」（落败的一边另存为该目录下未跟踪的 `<skill>-copy`，不丢内容）。自动同步只处理无歧义的部分，冲突只在结果区留「N 个冲突待处理」入口。
- 顶部提供「立即同步」「刷新」「自动同步」开关与「打开文件夹」；自动同步默认开启、按项目可关，只在进入项目、刷新或手动同步时执行，不监听文件变化；没有勾选任何目录时不写盘。
- 行菜单提供「移除某目录副本」与「卸载」（删除所有已跟踪副本并移除记录）；两者都要求二次确认，且只删除记录确认属于本项目的目录。

## 安全与一致性

- 每次替换或删除前先把目标目录备份到 `backups/projects/<项目>/<时间>/<目录>/<skill>/`；一批动作里任一失败就按备份整批回滚，项目记录不写。回滚也失败时，错误信息会同时给出原始失败原因与回滚问题。
- 被记录写进仓库要提交的目录一律原子写（临时文件 + 改名），没有变化时不重写，避免每次进入项目都让 `git status` 变脏。
- 符号链接与 Windows junction 一律拒绝跟随：目录是链接、或目录内含链接时，该格子按「状态未知」处理——既不判定为新增也不判定为删除，绝不参与删除传播，因此不会出现「一个 agent 的链接目录把另一个 agent 的健康副本删掉」。
- 被停用的 agent 对应的目标目录本轮跳过并明确提示，既不清除勾选也不写入界面看不见的目录；已停用的目标仍以「不可用」列显示，可以取消勾选。
- 记录文件损坏时直接报错并提示，不当成空表覆盖，不静默丢失归属。

## 已知边界

- **能力闸**：三个项目级落点尚未逐个完成真机验证，因此当前 `PROJECT_SKILL_DIRS` 全部标记为待实测——矩阵里这些列显示「待实测」，不提供勾选，「立即同步」按钮禁用并说明原因。按项目约定，只有真机写入证据才能把某一列升为可用（`docs/superpowers/specs/2026-10-26-project-level-skills-design.md` §6）。
- 本期只做「查看、勾选、同步、冲突裁决、移除副本、卸载」。从仓库 / ZIP / 本地目录**安装到项目目录**、以及项目级的在线更新，放在下一个计划；项目级 MCP（涉及密钥不能随仓库提交）单独立项。
- 冲突弹框目前列出各目录并给出「修改时间最新」的推荐，不做逐文件 diff 对比。
