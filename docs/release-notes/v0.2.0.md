# CC Switch X v0.2.0

本版本新增托盘驻留、全局代理与 Skills 发现，安装版可直接从 v0.1.0 升级。

- 新增系统托盘：开启「关闭窗口时最小化到托盘」后，关闭窗口不再退出应用；单击托盘图标或选择「显示主窗口」可恢复，托盘菜单也可直接退出。
- 新增「网络」页：支持配置 http / https / socks5 / socks5h 代理（可带用户名密码），并在保存前测试连通性。代理会应用到 Skills 下载、skills.sh 搜索和应用更新检查。
- Skills 新增「发现」：可添加、启用或停用技能仓库，浏览仓库内的技能并批量安装到指定 Agents；也可直接搜索 skills.sh 并安装。
- 应用更新检查同样走已配置的代理，网络受限环境下更新更可靠。
- 发布工作流升级到 Node 24 运行时，构建与发布流程保持不变。
