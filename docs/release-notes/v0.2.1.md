# CC Switch X v0.2.1

本版本将界面样式与字体对齐 cc-switch，并修复 ZIP 解压遇到符号链接时整包失败的问题。

- 界面字体改用 cc-switch 的系统字体栈（SF Pro / 苹方 / Segoe UI / 微软雅黑），正文基准 14px。
- 亮/暗色语义色、阴影与圆角补齐到 cc-switch v7 设计 token；对话框、菜单和遮罩统一新层级。
- Rules、Subagents、Hooks、会话浏览与导入等旧面板改用统一的语义色和表单控件，不再残留硬编码的 slate / red / amber 配色。
- Skills 仓库下载的 ZIP 若含符号链接，将跳过链接条目继续解压，不再整包失败；越界路径仍会被拒绝。
