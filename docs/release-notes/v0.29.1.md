# CC Switch X v0.29.1

这一版修掉 v0.29.0 调用统计的两处误报，并让会话扫描不再卡住整个界面。

## Skill 调用统计

- 未部署给任何 agent 的 Skill 不再显示调用次数：内置同名 Skill（例如内置的 `code-review`）的调用不会再算到未启用的同名资产上。
- 同一资产在会话里会用两种名字调用——部署目录名（资产 id）与 `SKILL.md` 的 frontmatter name——统计改为两者合并。例如 `humanizer-zh` 的 26 次（短名）与 28 次（目录名）现在显示为 54 次。
- Skills 页默认排序改为「调用次数从高到低」。

## 会话扫描与索引

- 扫描改为「发现 → 索引快照 → 解析（不持锁）→ 分批落库」：解析大文件期间不再长时间独占索引锁，MCP 等其它页面的读取不会排队卡死。
- 会话删除时的全文索引清理改为按 rowid 精确删除，单次删除从约半秒降到毫秒级；过期会话清理合并成小批次。
- 索引格式升级到 v2：首次启动会清空会话缓存并按新格式重建，`assets/` 与运行历史不受影响。升级后首次进入会话页需要重新扫描一次；Skills 页点「更多操作 → 刷新调用统计」即可恢复计数。

## 验证

- `cargo test`：单测 692 通过，集成测试全部通过，2 项真机用例默认忽略。
- `pnpm test`：278 通过（27 个文件）。
- `pnpm build`（含 `tsc -b`）、`cargo check` 与 `node scripts/check-release-version.mjs v0.29.1` 通过。
