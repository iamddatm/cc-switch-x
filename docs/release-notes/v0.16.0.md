# CC Switch X v0.16.0

这一版换了应用图标，Agents 页支持拖动排序，并给 WebDAV 云备份加了一个独立于全局代理的开关。

## 新图标：透明底的 X

- 主形从 8 辐放射改为 **4 条 45° 辐条**，构成 X；中心橙色签名点保留，作为与应用内 `--action` 同色的识别点。
- 取消深色圆角方底，整枚图标只有 X 本体，四角全透明（alpha=0）。深色任务栏上不再需要一块底板衬托，浅色桌面上也不会出现一块突兀的白底。
- 配色沿用上一轮选定的青绿 `#2BB673` → 天蓝 `#38BDF8`。辐条粗细、外端半径与中心点半径随辐条数量同步放大，16px 下仍能读出四条腿。
- 全套 PNG / ICO / ICNS 由 `pnpm tauri icon` 从 1024px master 重新生成；窗口图标、任务栏图标与托盘图标同源，标题栏复用 `128x128@2x.png`。
- 生成器 `scripts/gen-icon-candidates.py` 新增 `--no-tile`（去底）与 `--spoke-width` / `--spoke-outer` / `--dot-radius`（按边长比例调几何），产物落在 gitignore 的 `icon-lab/`。

## Agents 页支持拖动排序

- 整行拖拽，松手即保存；顺序记在本机设置的 `agentOrder`（`null` = 按内置注册表顺序，未列出的 agent 排在已列出的之后）。它只影响显示，不碰启用范围与已部署文件。
- 排序在 `list_agents` 里统一应用，因此不只是 Agents 页——Mcp / Rules / Prompts / Skills / Subagents / Hooks 面板的 agent 列顺序会一起跟着变。
- 拖动时原行半透明、目标行高亮；只接受本列表内部拖过来的行，外部拖入的文本不会被误当成排序。
- Windows 上 WebView2 自带的拖放处理器会吞掉 HTML5 拖放事件，因此主窗口配置了 `dragDropEnabled: false`。项目内没有任何「拖文件进窗口」的功能，不损失既有能力。

## WebDAV 云备份可以不走代理

- 网络页新增 **「WebDAV 云备份走代理」**，默认勾选，旧设置文件读进来行为不变。
- 关掉后云备份的上传、下载、状态读取与连通性测试全部直连；Skills 下载、skills.sh 搜索、应用更新等其他出站请求仍按全局开关走代理。代理全局开着也能只让 WebDAV 直连。
- 该选择独立于代理地址：清空代理地址后仍保留，重新填地址不用再勾一次。

## 验证

- `pnpm test` 214 通过（26 个文件），新增「拖行写入新顺序」与「WebDAV 单独不走代理」两个用例。
- `cargo test --lib` 566 通过；新增 `agent_order_overrides_the_registry_order_and_keeps_unlisted_last`、`set_agent_order_validates_and_deduplicates`、`webdav_proxy_switch_persists_independently_of_the_proxy_toggle`。
- `pnpm build`（含 `tsc -b`）、`cargo check` 与 `node scripts/check-release-version.mjs` 通过。
- **未覆盖**：拖动排序只在 jsdom 的合成拖放事件下验证过，没有在真机 WebView2 上实际拖一次；WebDAV 直连也没有接真实服务端验证，仅由「关掉开关后不再构造代理客户端」这一层保证。
