# CC Switch X v0.22.0

这一版集中修两处日常使用里最硌手的地方：会话页的长列表滚动与分组筛选，以及 Skills「发现」页的读取速度、仓库统计口径和来源跳转。

## 会话：头部固定，长列表可回到顶部

- 会话列表页的页头与筛选栏固定在滚动区之外；列表滚动超过约六行后，右下角出现「回到顶部」按钮。根容器改为按 flex 剩余高度布局，落盘提示条出现时也不会把整个窗口顶出滚动。
- 打开会话后的阅读页原来「返回列表 + 标题 + 元信息 + 全部消息」一起滚，现在拆成固定的顶部操作区（返回列表 + 会话标题）和独立滚动的消息区；消息区长滚后同样提供「回到顶部」。
- 修复「按时间 / 按项目」在搜索结果下点了没反应：命中列表不再走平铺分支，而是按当前分组方式重新组织。搜索命中按相关度排序，组内不再按更新时间重排；按项目分组时默认展开且不可折叠，避免切过去像空列表。
- 新增「按项目筛选」下拉（全局范围、两个项目以上时出现）：按项目名与路径区分同名仓库；筛选后应用下拉的数量、搜索结果、空状态文案与分组切换都按筛选集合计算。只剩一个项目时隐藏没有信息量的分组切换。

## Skills 发现：先读缓存，只拉需要的仓库

- **读取慢**的根因是每次进入发现页都会把所有参与仓库的 GitHub 归档整包下载、解压、扫描；而已安装 Skill 的来源仓库会被自动并入，实际一次要拉十几个仓库。
- 发现结果现在按仓库缓存到 `<storeRoot>/local/skill-discovery/`（`local/` 不同步、不进备份），10 分钟内再次进入直接复用扫描结果；已安装标记每次都按当前真源重算，不会停留在旧状态。手动点刷新会绕过缓存强制重新下载。
- 默认只读取配置为启用的仓库。已安装 Skill 的来源仓库移到筛选下拉的第二段「来自已安装 Skill（勾选后读取）」，默认不勾选、不下载；勾选后才作为 `extraRepos` 传给后端抓取。
- 修复「显示的仓库和实际的不符」：页签的 `仓库 · N` 与下拉的 `N/M` 都按实际勾选、实际读取的仓库统计，`M` 与下拉里列出的条目数一致，不再把十几个隐式来源仓库算进数字里。
- 发现页每个 Skill 行新增「在 GitHub 打开」：仓库发现行直达 `tree/<branch>/<skill 路径>`，skills.sh 行打开来源仓库首页。新增后端命令 `open_external_url`，只接受 `https` + `github.com`，经系统浏览器打开且不拼 shell 字符串。

## 说明

- 升级后首次进入发现页仍需下载一次配置的仓库归档（缓存为空），之后 10 分钟内再次打开直接读缓存；点刷新会重新下载。
- 已安装来源仓库的勾选状态不持久化：重新进入发现页仍按「只读配置仓库」开始，需要时再勾选。
