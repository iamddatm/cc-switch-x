# CC Switch X v0.14.0

这一版让开机自启真正「后台驻留」：登录系统后应用直接待在托盘里，不再弹出主窗口打断你。

## 开机自启隐藏到托盘

- 登录项改为带 `--autostart` 参数启动，应用识别到该参数后只驻留托盘，点托盘图标才显示主窗口。
- 主窗口默认不可见，由启动流程按需显示，避免开机自启时窗口闪一下。
- Windows 登录项命令行为可执行文件路径加上引号：安装目录含空格（`CC Switch X`）时，追加参数后系统仍能正确定位程序。
- 已开启自启的用户无需手动关开：升级后第一次启动会把旧登录项补写为带参数的命令，下次开机即隐藏到托盘。只补写当前仍指向本程序的条目，开发构建与便携副本不会改写已安装版本的登录项。
- 设置页「开机时自动启动」的说明同步为实际行为。

## 验证

- `cargo test` 553 通过：新增 `--autostart` 精确匹配与「只为裸路径旧条目补写」的判定测试；`pnpm test` 212 通过（26 个文件）；`pnpm build` 与 `cargo check` 通过。
- 实机验证：以 `--autostart` 启动时主窗口 `visible=False`，正常启动 `visible=True`；运行调试构建后用户登录项未被改写。
- **未覆盖**：未做真实重启/注销验证开机自启路径；macOS 登录项不接收启动参数，该平台行为保持不变。
