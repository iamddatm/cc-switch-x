# CC Switch X v0.30.0

这一版让已安装 Skill 的来源仓库自动进入发现列表，并把 Skills 页的搜索与筛选重新分层。

## Skill 仓库

- 启动时扫描已安装 Skill 的 `.meta.json` 来源，把尚未配置的仓库自动加入「已配置仓库」并启用；应用内安装 Skill 成功后也会立即登记，无需重启。
- 在「管理 Skill 仓库」里删除的仓库不会被自动加回；手动重新添加即恢复，仓库列表上限仍为 50。
- 管理页底部说明同步补充了删除后的行为。

## Skills 页布局

- 搜索框统一到「已安装 / 发现」共用的页签行右端，切换视图位置不变；趋势页不显示搜索框，但槽位固定。
- 已安装页的状态 / 来源 / Agent 收进一个「筛选」下拉，激活时显示「筛选 · N」；仓库多选保留独立入口，排序靠右显示当前选项。
- 项目级 Skills 面板同步改用同一套结构（渲染目录 / 部署状态 / 来源）。
- 发现页「管理仓库」收进仓库下拉底部；仓库勾选入口改名为「选择仓库：x/y」，与「仓库 / skills.sh / 趋势」页签区分。

## 修复

- 会话扫描结束后发送 `sessions-scanned` 事件：Skills 页在后台扫描完成时自动刷新调用统计。扫描失败时同样通知，因为已提交的批次可能部分成功。
