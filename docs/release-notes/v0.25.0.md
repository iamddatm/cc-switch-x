# CC Switch X v0.25.0

这一版让已安装的 Skill 能直接回到来源查看，并给列表行补上右键菜单：同一个 Skill 的查看、编辑、打开来源、检查更新与删除，不必再绕到行尾的「⋯」。

## 打开 Skill 来源

- 列表行右侧的来源徽标变成可点击：点 `owner/repo` 即在系统默认浏览器打开来源页面。
- 打开地址优先 SKILL.md 的 GitHub 文件页（精确到该 Skill 所在目录），没有时退回仓库页。
- ZIP 安装与本地目录导入的 Skill 来源是本地路径，不提供浏览器入口；行为与之前一致。

## 行右键菜单

- 在「已安装」页的任意 Skill 行上右键，即可在指针位置弹出一组操作：查看、编辑、在浏览器打开来源、检查更新、更新、删除。
- 菜单项与行尾「⋯」完全一致，任选一种入口效果相同。
- 点击菜单外、按 Esc 或选中一项即关闭；靠近窗口边缘时菜单会自动往视口内收。

## 验证

- `pnpm test`：**266 通过**（27 个文件，v0.24.0 是 263），新增覆盖：菜单打开来源、徽标点击打开来源且不触发详情、右键菜单与「⋯」操作一致。
- `pnpm build`（含 `tsc -b`）与 `node scripts/check-release-version.mjs` 通过（v0.25.0）。
- 后端 `open_external_url` 沿用既有校验，只放行 GitHub 的 HTTPS 链接，本次未改后端。
