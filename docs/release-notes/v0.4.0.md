# CC Switch X v0.4.0

本版本新增独立「备份」面板：既可以把可移植资产打包成快照跨机器恢复，也可以用 Git 维护本地提交历史并同步到远端。

- 新增手动快照与自动快照：自动间隔支持关闭或 6/12/24/48/168 小时，按保留份数清理旧快照；支持重命名、删除与一键恢复。
- 快照只包含 `assets/`、`agents/` 与 `.gitignore`，不会打包本机 `local/`、`state/`、密钥、索引、日志与历史备份，换机器恢复不会带入设备级数据。
- 恢复采用白名单覆盖：只写资产、内置 Agent 配置与 `.gitignore`；恢复前自动创建安全快照，失败时按安全快照回滚。
- 备份面板展示快照、写入备份、日志与索引的占用空间，可打开备份目录并清理写入备份或日志。
- 新增 Git 备份：初始化仓库后可自动提交本地变更、推送远端，并在启动与定时任务中拉取远端更新；提交身份与签名只在单次命令内临时注入，不修改全局 Git 配置。
- 远端冲突时暂停自动同步并列出冲突文件，可选择保留本地（`--force-with-lease` 强推）或保留远端（先创建安全快照再重置），两种操作都需要二次确认。
- 支持从 Git 历史恢复某次提交：先保存当前变更与安全快照，再生成新的恢复提交，不会丢失后续历史。
- 恢复快照、拉取远端或恢复提交后会清理派生的 Agent 开关与漂移状态并重建索引，避免展示过期状态。
- Skills 来源徽标改为 `owner/repo`，分支与源地址移入悬停提示；更新时间移到标题下方；桌面端禁用 WebView 默认右键菜单。
