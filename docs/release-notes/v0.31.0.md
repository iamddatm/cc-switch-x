# CC Switch X v0.31.0

这一版新增第七类真源资产「命令」，把 Claude Code 的自定义斜杠命令（`~/.claude/commands/<id>.md`）纳入统一管理，与其余资产一起备份、同步与漂移处置。

## 命令资产

- 新增 `assets/commands/<id>.md` 真源：文件内容**逐字保留**，frontmatter（`description` / `argument-hint` / `allowed-tools` …）与正文都不重排，避免制造无意义的 diff。
- 命令名来自文件名：`review.md` 对应 `/review`；列表副标题优先取 frontmatter 的 `description`，没有则取正文第一行。
- 侧栏新增「命令」面板：左侧列表 + 「从 agent 目录扫描导入」，右侧整份 markdown 编辑器与「同步到」开关矩阵。
- 扫描把 `~/.claude/commands/*.md` 原样收进真源；刚落盘再扫描计为「未变」，不会造出假 diff。
- 落盘归属沿用台账 + 原文双重判定：同名外来文件、手改过的自家文件一律不动，取消勾选也不会误删。
- 漂移处置与 Rules / Subagents 一致：工具侧被手改即报告，只能在「采纳磁盘」或「重刷真源」里二选一。
- 备份、git 同步与云备份按既有资产目录机制自动覆盖 `commands/`。

## 能力范围

- 仅 **Claude Code** 声明 `~/.claude/commands` 落点并标为已实测；其余 agent 该项为「不支持」，不出开关。
- 当前只扫描 `commands/` 顶层的 `.md`；嵌套命名空间子目录与项目级 `.claude/commands` 暂未纳入。
