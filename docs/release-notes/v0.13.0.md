# CC Switch X v0.13.0

这一版在「从云端恢复」的确认弹窗里补上了备份包的身份信息，覆盖真源前能先看清要拿哪台机器、什么时候传的包。

## 云端恢复前先核对备份包

- 「从云端恢复」确认弹窗新增备份包信息卡：**来源设备与应用版本、上传时间、包含文件数、包大小**，四项来自云端 `manifest.json`。
- 旧版上传的裸包没有 manifest 时明确标注「旧版裸包（无 manifest）」，只展示能确认的大小；来源无法核对时不再默认放行。
- 云端没有可恢复备份、状态读取失败、manifest 解析失败、或包由不兼容版本上传（manifest schema 不匹配）时，弹窗内直接给出对应提示，恢复仍走原有确认流程。
